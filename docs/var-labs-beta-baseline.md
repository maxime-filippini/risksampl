# VaR Labs beta baseline

This branch begins the VaR Labs beta revival from the legacy Risksampl repository state. It is a stable starting point, not a product redesign.

## Legacy Risksampl reference

The existing SvelteKit application, Python worker, Drizzle schema and migrations remain the legacy reference. Their current behavior, database shape, data-retrieval jobs, and user interface have not been redefined by this baseline work.

The beta starts on `chore/var-labs-beta-baseline`, created from `develop` commit `ce336ab7969edf30bd386d9e148aca7e21ecb2a0`. Future VaR Labs work should make its intended product changes explicitly rather than treating legacy behavior as new beta requirements.

## What this baseline establishes

- Frontend type checking has no Svelte diagnostics.
- Frontend formatting and ESLint checks pass. Generated Drizzle metadata and OpenAPI types are excluded from formatting checks; they remain source-controlled artifacts generated by their respective tools.
- Worker tests pass.
- The baseline contains no unrelated local working-tree changes. In particular, a pre-existing local deletion of `CLAUDE.md` is intentionally not part of this branch's commits.

## Verification

Run these commands from the repository root before beginning new beta work:

```bash
cd web && bun run check
cd web && bun run lint
cd worker && uv run pytest
```
