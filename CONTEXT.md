# VaR Labs

VaR Labs publishes reproducible risk snapshots for comparing Value at Risk
models across portfolios.

## Language

**Definition**:
A versioned description of a portfolio or VaR model. The definition is the same
domain concept regardless of whether its provenance is public, private,
reference, fixed, or custom.
_Avoid_: Benchmark definition, private definition, custom definition

**Snapshot**:
An immutable, date-bound publication of VaR results tied to the exact
definitions that produced them.
_Avoid_: Benchmark snapshot
